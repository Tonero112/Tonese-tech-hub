TONESE TECH HUB WEBSITE
========================

Files:
- index.html       Main website
- privacy.html     Privacy policy
- terms.html       Terms of service
- styles.css       Website styling

Recommended free deployment:
1. GitHub Pages can host static HTML for free on a public repository under GitHub Free.
2. Upload these files to the repository.
3. Enable GitHub Pages.
4. Add tonesetechhub.online as the custom domain.
5. Configure the DNS records shown by GitHub at Hostinger.
6. Keep the domain verification TXT record in DNS.

Alternative:
Cloudflare Pages also supports custom domains and a Free plan.

Important:
- Replace or update any content that is not factually accurate before publishing.
- Do not publish sensitive personal information or the CAC tax identification number.
- Keep the business name, website domain and company email consistent with the information submitted to D-U-N-S and Samsung.
